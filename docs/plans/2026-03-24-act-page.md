# Act Page ("Agir") — Implementable Requirements

## Goal

Build the `/act` page that guides users through a 4-step flow: find their water company → see a color-coded action sheet → contribute data → join the project.

---

## Page Layout

Single scrollable page, 4 clearly separated sections (steps), each with a numbered header. Max-width container (~`max-w-5xl`), consistent with rest of site.

---

## Step 1: Find Your Water Company

**Component:** `ActSearchSection`

### UI
- Heading: "Step 1: Find Your Water Company"
- Subtext explaining the purpose
- Search input (reuse/extend existing `SearchBar` pattern) with placeholder "Enter your city, postal code, or address..."
- "Search" button
- Autocomplete dropdown showing matching distribution zones as user types (debounced, min 3 chars)

### Search Results Panel
When user selects a distribution zone, an expandable panel appears below the search bar showing:

| Field | Source | Notes |
|---|---|---|
| Distribution zone name | `DistributionZoneFields.Name` | |
| Country | `DistributionZoneFields.Country` | Linked record |
| Water company (actor) | `DistributionZoneFields.ActorName` | Already in API |
| Water company email | `DistributionZoneFields.ActorEmail` | Already in API |
| PVC Level | `DistributionZoneFields['PVC Level']` | Nullable |
| VCM Level | `DistributionZoneFields['VCM Level']` | Nullable |
| Municipalities | Need new fetch | List of municipality names in the zone |

### Color Code Derivation
The VCM/PVC levels need to map to a color code. **Open question:** what are the thresholds? For now, assume:

| Color | Meaning | Condition |
|---|---|---|
| 🟢 Green | Safe | VCM Level is null or "Conforme" |
| 🟡 Yellow | Caution | VCM Level is "Vigilance" or PVC Level is non-null but low |
| 🟠 Orange | Warning | VCM Level is elevated but below limit |
| 🔴 Red | Danger | VCM Level exceeds limit |

**Note:** The exact mapping depends on what values `VCM Level` and `PVC Level` actually contain in NocoDB. This needs to be confirmed with the data team.

### Search Approach: Denormalized `SearchIndex` Field

A `SearchIndex` text field on the `DistributionZone` table in NocoDB concatenates zone name + municipality names + actor names. A Python script populates/refreshes it. The API searches this single field, always returning zones directly — no cross-table queries or merge logic.

#### Python script (`scripts/build_search_index.py`)
- Fetches all DistributionZone records with linked Municipality names and Actor names
- Concatenates into a single string: `"{zone_name} | {municipality1}, {municipality2} | {actor1}, {actor2}"`
- Writes back to `SearchIndex` field via NocoDB API
- Run manually or on a schedule when data changes

#### API Changes
- **Modify** `/api/searchbydistributionzone` to search `(SearchIndex,like,query)` instead of `(Name,like,query)`, return Name + Country + ActorName for display in dropdown
- **New** `/api/distributionzone/[id]` — full record fetch on selection, returning:
  - `PVC Level`, `VCM Level`
  - `ActorName`, `ActorEmail`
  - Municipality names
  - Latest analysis date (if available via `Analyses` linked records)

#### Search UX
- Debounced type-ahead (300ms, min 3 chars) replaces current button-triggered search
- Dropdown shows matching zones with country + actor name as context
- Selection triggers detail fetch and renders results panel

## Step 2: Action Guide ("Que dois-je faire ?")

**Component:** `ActionGuide`

Static content — no conditional rendering. Presents all three scenarios on the page so users can identify their situation and follow the relevant guidance. This works independently of Step 1 (no search required).

### Layout
Two-column on desktop (content left ~60%, sticky sidebar right ~40%). Single column on mobile.

### Left Column: Scenarios

Three collapsible sections (accordion), each with a colored header badge. All start **collapsed** — user opens the one matching their situation.

#### 🟢 Votre eau est conforme
- Nothing to do
- Stay vigilant: CVM pollution can appear over time (aging pre-1980 PVC pipes)
- CTA: share private analysis data (anchor to Step 3)

#### 🟡🟠 Vigilance recommandée
- Caution banner: "Vous pouvez continuer à boire l'eau, mais restez prudent — surtout pour les nourrissons et personnes fragiles"
- Numbered sub-steps (same as Red below, minus "stop consuming"):
  1. Contact your water provider (request testing, demand specific control points, 30-day CADA deadline, demand pipe replacement if non-compliant, right to bottled water, private testing option ~€40–100)
  2. Contact your elected official
  3. If no action → consider legal action

#### 🔴 Action urgente requise
- Alert banner (red): "Cessez immédiatement de consommer l'eau du robinet"
- Numbered sub-steps:
  1. Stop consuming water (do not drink or cook, CVM inhalation risk)
  2. Contact your water provider (same sub-steps as yellow/orange)
  3. Contact your elected official
  4. If no action → consider legal action

### Right Column: Sticky Sidebar
- **Important reminder** box: as a subscriber you're paying for a service, supplying safe water is a legal obligation, you have the right to demand solutions
- **Letter templates** — 3 template cards stacked vertically:
  - Letter to the mayor
  - Email compagnie d'eau
  - Letter to MP
  - Each opens a modal (`sheet.tsx`) with full template text + copy button
- **⚠️ Notice**: "Keep written records of all communications"

### Data Dependencies
- **Email templates**: hardcoded in English. No i18n for now.
- **Legal action link**: static external URL (confirm with team)

### Files
- `app/[locale]/act/components/ActionGuide.tsx` — two-column layout with accordion
- `app/[locale]/act/components/ScenarioSection.tsx` — reusable accordion item (color badge + numbered steps)
- `app/[locale]/act/components/ActionGuideSidebar.tsx` — sticky sidebar with templates + legal reminder
- `app/[locale]/act/components/TemplateModal.tsx` — modal showing template text with copy button

## Step 3: Contribute Data

**Component:** `ContributeDataSection`

Two sub-sections side by side (on desktop) or stacked (mobile), matching the wireframe's 3-column layout.

### 3a. Contact Decision-Makers
- Heading + explanation text
- 3 clickable template cards:
  - "Template : Letter to the mayor"
  - "Template: Email to water company"
  - "Template : Letter to MP"
- Each opens a modal/sheet with the template text, pre-filled with zone info from Step 1 if available, and a copy button
- "Soumettre une correction" button (links to correction form or email)

### 3b. Share Your Data
Form fields:
- Data type (dropdown: analysis report, PVC presence info, correction, other)
- Document source (text input, e.g. "Rapport annuel 2024")
- File upload (PDF, Excel — drag & drop zone)
- "Soumettre les données" button

**Submission:** For MVP, send as email with attachment (pre-filled `mailto:` link or simple backend endpoint). Alternatively, POST to a NocoDB form or dedicated API route.

### 3c. Correction/Feedback
- Short text: "Vous avez obtenu une réponse ou détecté une erreur ?"
- "Soumettre une correction" button → opens same form or dedicated email

### Files
- `app/[locale]/act/components/ContributeDataSection.tsx`
- `app/[locale]/act/components/TemplateCard.tsx`
- `app/[locale]/act/components/DataSubmissionForm.tsx`
